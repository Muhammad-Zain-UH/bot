Zoya Intraday Bot — Detailed Architecture
==========================================

1. SYSTEM OVERVIEW
------------------
This is a production-grade, regime-aware, multi-layer intraday trading bot for
XAUUSD (Gold), built in Python and designed to run against MetaTrader 5 (MT5).
It operates on a 5-second main loop and uses a 10-layer sequential decision
pipeline (L0-L9, plus L10) to validate every trade before and after execution.
The architecture is modular, with each layer in its own file, and supports live
MT5 execution, simulation mode, state persistence across restarts, and graceful
error recovery. The system classifies market regimes dynamically and adjusts
risk, spread tolerance, and layer bypass logic accordingly.

4. DETAILED LAYER PIPELINE (L0-L8)
------------------------------------

L0: PRE-TRADE GATES
  File: main_production.py :: check_pre_trade_gates()
  +------------------------------------------------------------------+
  | Gate 1: Daily Loss Limit                                         |
  |   current_daily_loss < -(balance * 5%)                           |
  |   FAIL -> BLOCK ALL -> sleep 60s                                 |
  |                                                                  |
  | Gate 2: Spread Monitoring                                        |
  |   NOT checked here (deferred to L8 Entry Trigger)                |
  |   Reason: spread tolerance is REGIME-SPECIFIC                    |
  |                                                                  |
  | Gate 3: Session Validation                                       |
  |   DEAD (22:00-03:00 UTC) -> BLOCK                                |
  |   LONDON / NY -> PASS (Prime tier)                               |
  |   ASIAN -> PASS (Tier 2, regime applies risk)                    |
  +------------------------------------------------------------------+
                                | PASS
                                v
L1: H4 BIAS
  File: bias_engine.py :: get_h4_bias()
  +------------------------------------------------------------------+
  | Input: H4 indicators (EMA20, EMA50, ATR, close) + Daily data     |
  |                                                                  |
  | Rules:                                                           |
  | * EMA20 vs EMA50 separation > ATR-scaled threshold               |
  | * Last 2 closes vs EMA20 confirmation                            |
  | * Daily midpoint confirmation (price vs daily H/L mid)           |
  | * Daily close invalidation (flip if broken)                       |
  |                                                                  |
  | Output: BULLISH | BEARISH | NEUTRAL + strength 0-10             |
  |         + swing_high, swing_low, ema_distance                    |
  +------------------------------------------------------------------+
                                |
                    NEUTRAL -----+
                     BLOCK -> return analysis
                     BULLISH/BEARISH -> continue
                                |
                                v
L2: H1 STRUCTURE
  File: structure_engine.py :: get_h1_structure()
  +------------------------------------------------------------------+
  | Input: H1 data + expected_bias (from L1)                         |
  |                                                                  |
  | Rules:                                                           |
  | * Find H1 swing highs/lows (fractal pattern)                     |
  | * BULLISH: last 5 candles show HH/HL progression                 |
  | * BEARISH: last 5 candles show LH/LL progression                 |
  | * ATR check: H1 ATR < 8 pips = DEAD CALM -> BLOCK               |
  | * Close beyond last swing = BROKEN -> BLOCK                      |
  |                                                                  |
  | Output: VALID | BROKEN | UNKNOWN + confidence 0-10              |
  |         + last_swing_high, last_swing_low                        |
  +------------------------------------------------------------------+
                                |
              BROKEN/DEAD CALM -----+
               BLOCK -> return analysis
               UNKNOWN -> WARN but PASS (confidence=0)
               VALID -> continue
                                |
                                v
L3: M15 PULLBACK
  File: pullback_detector.py :: get_m15_pullback()
  +------------------------------------------------------------------+
  | Input: M15 data + expected_bias + regime_info                    |
  |                                                                  |
  | Bypass Logic:                                                    |
  | * If regime_info["bypass_l3"] == True -> SKIP gate               |
  |   (MICRO_SCALP momentum entries don't need pullback)             |
  |                                                                  |
  | Standard Rules (when not bypassed):                              |
  | * Detect counter-trend phase on M15                              |
  | * Bullish: EMA20 cross below EMA50 + LH/LL printing              |
  | * Bearish: EMA20 cross above EMA50 + HH/HL printing              |
  | * Volume declining into pullback (good)                          |
  | * Fib depth 38%-62% ideal                                        |
  |                                                                  |
  | Output: pullback_detected (bool) + quality (0.0-10.0)            |
  |         + volume_warning flag                                     |
  +------------------------------------------------------------------+
                                |
                     NOT DETECTED --+
                      BLOCK -> return analysis
                      QUALITY < 1.5 -> BLOCK
                      PASS -> continue
                                |
                                v
L4: LIQUIDITY POOLS
  File: liquidity_engine.py
  +------------------------------------------------------------------+
  | identify_liquidity_pools():                                      |
  |   * sweep_pool: stop-loss cluster level + score                  |
  |   * tp_pool: take-profit cluster level + score                   |
  |                                                                  |
  | assess_liquidity_gate():                                         |
  |   * sweep_score threshold                                        |
  |   * sweep_distance from current price                            |
  |   * tp_score quality                                             |
  |                                                                  |
  | Output: pools_found + sweep_pool + tp_pool + state (PASS/BLOCK)  |
  +------------------------------------------------------------------+
                                |
                          BLOCK --+
                           BLOCK -> return analysis
                           PASS -> continue
                                |
                                v
L5: SWEEP + STRUCTURE
  File: sweep_detector.py :: get_sweep_and_structure()
  +------------------------------------------------------------------+
  | Input: M15 + H1 data + L4 sweep level + bias direction           |
  |                                                                  |
  | Rules:                                                           |
  | * Price sweeps liquidity pool (stop hunt)                        |
  | * CHoCH / BOS detection                                          |
  | * Sweep direction matches bias?                                  |
  |                                                                  |
  | Output: gate_state (PASS | WATCH | BLOCK)                        |
  |         + sweep_confirmed + setup_grade + gate_reason            |
  +------------------------------------------------------------------+
                                |
                    WATCH --------+
                     WAIT -> return analysis (L5_SWEEP_WAIT)
                     NOT CONFIRMED -> BLOCK
                     WRONG DIRECTION -> BLOCK
                     PASS -> continue
                                |
                                v
L6: POI QUALITY
  File: poi_engine.py :: identify_poi()
  +------------------------------------------------------------------+
  | Input: M15 + H1 data + direction + current_price                 |
  |                                                                  |
  | Bypass Logic:                                                    |
  | * If regime_info["bypass_l6"] == True -> SKIP gate               |
  |   (MICRO_SCALP doesn't need POI confluence)                      |
  |                                                                  |
  | Standard Rules:                                                  |
  | * Order blocks (OB) identification                               |
  | * Fair value gaps (FVG)                                          |
  | * Dynamic threshold:                                             |
  |   - sweep_confirmed=True -> threshold = 60                       |
  |   - else -> threshold = 70                                       |
  |                                                                  |
  | Output: best_poi + score + type + zone bounds                    |
  +------------------------------------------------------------------+
                                |
                     NO POI / SCORE LOW --+
                      BLOCK -> return analysis
                      PASS -> continue
                                |
                                v
L7: CONFIDENCE SCORE
  File: confidence_engine.py :: get_confidence_engine()
  +------------------------------------------------------------------+
  | Formula:                                                         |
  |   bias_component      = bias_strength      * 0.24                |
  |   structure_component = structure_confidence * 0.20               |
  |   sweep_component     = sweep_quality      * 0.20                |
  |   poi_component       = poi_score          * 0.20                |
  |   cohesion_component  = min(16, strong_signals * 4)              |
  |   session_bonus       = +8 (LONDON/NY), 0 (ASIAN), -15 (DEAD)   |
  |   + Fib confluence bonus                                         |
  |   + RSI neutral bonus                                            |
  |                                                                  |
  | Output: final_score (0-100) + grade + reasoning                  |
  |   * A+ : >= 85                                                    |
  |   * A  : >= 70 (REGIME_SCALP) or >= 55 (MICRO_SCALP)            |
  |   * REJECT: below threshold                                      |
  +------------------------------------------------------------------+
                                |
                     SCORE < THRESHOLD
                      BLOCK -> return analysis (L7_CONFIDENCE)
                      PASS -> continue
                                |
                                v
L8: ENTRY TRIGGER + REGIME SPREAD CHECK
  File: entry_engine.py :: get_entry_trigger() + detect_regime()
  +------------------------------------------------------------------+
  | Step 1: Spread Check (Regime-Specific)                           |
  |   * MICRO_SCALP: max 5 pips                                      |
  |   * REGIME_SCALP: max 7 pips                                     |
  |   * INTRADAY_SWING: max 10 pips                                  |
  |   Exceeds -> REJECTED                                             |
  |                                                                  |
  | Step 2: Entry Trigger Detection                                  |
  |   * Rejection candle (wick >= 2x body)                           |
  |   * Close in upper 50% (BUY) or lower 50% (SELL)                 |
  |   * Next M1 close confirmation                                    |
  |   * Volume > 20-candle baseline                                   |
  |   * RSI turning up/down                                           |
  |   * MACD histogram flip                                           |
  |                                                                  |
  | Step 3: evaluate_entry_for_regime()                              |
  |   * RR validation                                                 |
  |   * Entry mode (MARKET/LIMIT)                                     |
  |                                                                  |
  | Output: entry_triggered (bool) + setup_type + rr_ratio            |
  +------------------------------------------------------------------+
                                |
                     SPREAD WIDE --+
                      REJECTED -> return analysis
                      TRIGGER NOT FIRED -> WAIT
                      ALL PASS -> ENTRY_SIGNAL


5. EXECUTION & MANAGEMENT FLOW
--------------------------------
+--------------------------------------------------------------------------------+
|  EXECUTION PIPELINE                                                            |
|                                                                                |
|  entry_signal -> Risk Manager -> OrderExecutor -> MT5/Simulation              |
|       |               |                  |                                      |
|       |               |                  +-> Trade Persistence                 |
|       |               |                       save_active_trades()             |
|       |               |                                                          |
|       |               +-> calc_lot_size()                                        |
|       |                    lot = balance * risk_pct / (stop_dist * 10)         |
|       |                    clamped to [0.01, 1.0]                               |
|       |                                                                          |
|       +-> create_order()                                                        |
|            order_id, entry_price, SL, TP, RR, grade, metadata                 |
|       +-> execute_order()                                                       |
|            simulation=True -> simulated (5% random failure for testing)        |
|            simulation=False -> MT5 order_send() with retry (max 3 attempts)    |
|       +-> _OPEN_TRADES.append(trade_dict)                                       |
|                                                                                |
|  L9: Position Management (trade_manager.py)                                    |
|  For each open trade:                                                          |
|    * 1:1 RR hit  -> CLOSE_50PCT (50% closed, SL -> breakeven)                 |
|    * 1:2 RR hit  -> TRAIL_SL (SL trails at 50% of leg 2)                     |
|    * 1:3 RR hit  -> CLOSE_ALL (full TP)                                       |
|    * SL hit      -> CLOSE_ALL (stop loss)                                      |
|                                                                                |
|  L10: Feedback Loop (feedback_loop.py)                                         |
|    * log_closed_trade() -> closed_trades.json                                  |
|    * calculate_weekly_performance() -> win_rate, avg RR, PnL summary          |

15. KEY DESIGN PATTERNS
------------------------
- Sequential Gate Pipeline: Each layer returns a dict with a gate state. Any
  layer can BLOCK or WAIT, short-circuiting the rest.
- Regime-Aware Adaptivity: The same pipeline adapts risk, spread tolerance,
  layer bypass, and confidence thresholds based on market volatility (M5 ATR).
- State Machine for Trades: Trades progress through PENDING -> OPEN ->
  PARTIAL_CLOSE -> TRAILING_SL -> CLOSED, tracked by OrderExecutor and
  trade_manager.
- Graceful Degradation: Every major component is imported in a try/except block.
  If MT5 is unavailable, the bot runs in analysis/demo mode. If a layer is
  missing, analysis returns ERROR instead of crashing.
- Persistence + Backup: Active trades are saved every 10 loop iterations with
  automatic backup. On restart, restore_state() rehydrates _OPEN_TRADES.
- Retry Logic: Order execution retries up to 3 times with 0.5s delay. MT5 data
  fetch has 3 retry attempts with fallback to copy_rates_range.
- BOS Flip (L2): A broken H1 structure against the current bias is re-evaluated
  in the opposite direction, allowing the bot to trade a confirmed reversal
  instead of stalling.


16. LAYER DETAILS (L1-L10)
---------------------------

L1 - H4/H1 Bias (bias_engine.py)
  Purpose: Determine the ONLY allowed direction for the trade.
  Logic:
    - Scalp regimes use get_fast_bias() on H1 data.
    - INTRADAY_SWING uses get_h4_bias() on H4 data.
    - EMA20 vs EMA50 separation must exceed ATR-scaled threshold.
    - Last 2 closes must confirm bias direction.
    - Price must be on correct side of daily H/L midpoint.
  Output: BULLISH | BEARISH | NEUTRAL + bias_strength (0-10).

L2 - H1 Structure (structure_engine.py)
  Purpose: Confirm trend structure on H1 timeframe.
  Logic:
    - Detect swing highs/lows using fractal pattern (5-candle window).
    - BULLISH requires HH/HL progression; BEARISH requires LH/LL.
    - H1 ATR < 8 pips -> DEAD CALM -> BLOCK.
    - Close beyond last swing -> BROKEN -> BLOCK.
    - BOS Flip: If structure is broken in one direction, check if opposite
      direction has confirmed structure and flip bias.
  Output: VALID | BROKEN | UNKNOWN + structure_confidence (0-10).

L3 - M15 Pullback (pullback_detector.py)
  Purpose: Identify quality pullbacks in the direction of the bias.
  Logic:
    - Bypass: MICRO_SCALP bypasses this layer entirely.
    - Momentum Fallback: REGIME_SCALP without pullback gets a stricter
      momentum check (2+ consecutive M5 closes, volume above baseline,
      RSI band 55-75/25-45, distance < 1.2x ATR).
    - Standard pullback: Fib 38-62% retracement, EMA20/50 cross,
      volume declining.
  Output: pullback_detected (bool) + pullback_quality (0-10).

L4 - Liquidity Pools (liquidity_engine.py)
  Purpose: Identify stop-loss clusters (sweep pools) and take-profit clusters.
  Logic:
    - identify_liquidity_pools(): Scans M15/H1/H4/Daily for clustered
      highs/lows.
    - assess_liquidity_gate(): Validates sweep pool quality, distance from
      current price, and TP pool quality.
  Output: sweep_pool (level + score) + tp_pool (level + score) +
          state (PASS/BLOCK).

L5 - Sweep + CHoCH/BOS (sweep_detector.py)
  Purpose: Confirm stop hunt (liquidity sweep) and structure change.
  Logic:
    - Price must sweep the L4 liquidity pool.
    - Detect CHoCH (Change of Character) or BOS (Break of Structure) on H1.
    - Sweep direction must match bias direction.
  Output: gate_state (PASS | WATCH | BLOCK) + sweep_confirmed + setup_grade.

L6 - POI Quality (poi_engine.py)
  Purpose: Find high-probability entry zones (Order Blocks, Fair Value Gaps).
  Logic:
    - Bypass: MICRO_SCALP bypasses this layer.
    - identify_poi(): Scans M15/H1 for OB and FVG patterns.
    - Dynamic threshold: 60 if sweep confirmed, 70 otherwise.
  Output: best_poi (type, score, zone bounds).

L7 - Confidence Score (confidence_engine.py)
  Purpose: Aggregate all signals into a single confidence score with
           regime-specific weights.
  Formula:
    final_score = (
        bias_strength * weight_bias +
        structure_confidence * weight_structure +
        sweep_quality * weight_sweep +
        poi_score * weight_poi +
        min(16, strong_signals * 4) +
        session_bonus +
        fib_confluence_bonus +
        rsi_bonus
    )
  Regime Weights:
    - MICRO_SCALP: bias=0.20, structure=0.05, sweep=0.35, poi=0.20, cohesion=0.20
    - REGIME_SCALP: bias=0.24, structure=0.20, sweep=0.20, poi=0.20, cohesion=0.16
    - INTRADAY_SWING: bias=0.25, structure=0.30, sweep=0.15, poi=0.20, cohesion=0.10
  Thresholds: MICRO_SCALP >= 55, REGIME_SCALP >= 70, momentum fallback >= 75.
  Grades: A+ (>=85), A (>=threshold), REJECT.

L8 - Entry Trigger (entry_engine.py)
  Purpose: Confirm precise entry timing with M5/M1 candles.
  Logic:
    - Spread check (regime-specific, already validated at L0).
    - Rejection candle: wick >= 2x body, close in upper/lower 50% of range.
    - Next M1 close confirmation.
    - Volume > 20-candle baseline.
    - RSI turning up/down + MACD histogram flip.
    - evaluate_entry_for_regime(): Validates RR ratio and determines
      MARKET/LIMIT entry mode.
  Output: entry_triggered (bool) + setup_type + rr_ratio + entry_mode.

L9 - Position Management (trade_manager.py / manage_positions)
  Purpose: Manage open trades with strategic partial exits and SL adjustments.
  Logic (checked in order):
    - SL Hit: Immediate full close.
    - 1:1 RR: Close 50% position, move SL to breakeven.
    - 1:2 RR: Trail SL to 50% of leg 2 (lock partial profits).
    - 1:3 RR: Close remaining 100% at TP.
    - Breakeven Protection: If price retraces back to entry after SL moved to
      BE, close at breakeven + buffer.
  State Tracking: position_size, current_sl, sl_status, exit_1_1_taken,
                  exit_1_2_status.

L10 - Feedback Loop (feedback_loop.py)
  Purpose: Log closed trades and calculate performance metrics.
  Logic:
    - log_closed_trade(): Save to closed_trades.json.
    - calculate_weekly_performance(): Win rate, average RR, total PnL.
    - Auto-adjust parameters based on performance (if implemented).
